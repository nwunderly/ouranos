# Ouranos Privacy Policy

## Bot overview
Ouranos is a private moderation bot used to help moderate some of the communities I manage.

## Stored personal data
The bot stores infraction cases. These cases include:
* User ID and username of the user tied to the infraction
* User ID of the moderator who created the infraction
* Username(s) of the moderator(s) who have edited the infraction

## Data retention
* Infractions are stored until manually deleted.
